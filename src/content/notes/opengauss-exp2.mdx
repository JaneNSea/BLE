### 查询语句编写

```sql
-- 1. 学数据库的学生（课程名含“数据库”）
SELECT s.* FROM xs s
                    JOIN xk x ON s.xh = x.xh
                    JOIN kc k ON x.kcbh = k.kcbh
WHERE k.kcm LIKE '%数据库%';

-- 2. 没有授课的教师
SELECT js.* FROM js
                     LEFT JOIN sk ON js.jsbh = sk.jsbh
WHERE sk.jsbh IS NULL;

-- 3. 学生高峰所选课程的总学分
SELECT SUM(k.xf) FROM kc k
                          JOIN xk x ON k.kcbh = x.kcbh
                          JOIN xs s ON x.xh = s.xh
WHERE s.xm = '高峰';

-- 4. 教授必修课程的老师情况
SELECT DISTINCT js.* FROM js
                              JOIN sk ON js.jsbh = sk.jsbh
                              JOIN kc k ON sk.kcbh = k.kcbh
                              JOIN xk x ON k.kcbh = x.kcbh
                              JOIN xs s ON x.xh = s.xh
WHERE s.xm = '高峰' AND k.lx = '必修';

-- 5. 高峰选修了哪些系的课程
SELECT DISTINCT y.ymc FROM xyb y
                               JOIN js ON y.ydh = js.ydh
                               JOIN sk ON js.jsbh = sk.jsbh
                               JOIN xk x ON sk.kcbh = x.kcbh
                               JOIN xs s ON x.xh = s.xh
WHERE s.xm = '高峰';

-- 6. 计算机系学生所学的所有课程
SELECT DISTINCT k.kcm FROM kc k
                               JOIN xk x ON k.kcbh = x.kcbh
                               JOIN xs s ON x.xh = s.xh
                               JOIN xyb y ON s.ydh = y.ydh
WHERE y.ymc = '计算机学院';

-- 7. 查询所有学生的平均成绩
SELECT xh, AVG(cj) AS avg_score FROM xk GROUP BY xh;

-- 8. 查询不及格的课程及学生信息
SELECT s.xm, k.kcm, x.cj FROM xs s
                                  JOIN xk x ON s.xh = x.xh
                                  JOIN kc k ON x.kcbh = k.kcbh
WHERE x.cj < 60;
```

### 数据更新与删除

```sql
-- 更新学生 S001 的班级信息
UPDATE xs SET bj = '计科3班' WHERE xh = 'S001';

-- 更新学生 S002 的课程成绩
UPDATE xk SET cj = 95 WHERE xh = 'S002' AND kcbh = 'K01';
-- 先删除学生的选课记录（子表），再删除学生信息（主表）
DELETE FROM xk WHERE xh = 'S040';
DELETE FROM xs WHERE xh = 'S040';
```

## 实验结论

- 成功通过DataGrip 完成 openGauss 数据库的远程连接，能够正常执行 SQL 语句。
- 完成了主表与子表的数据插入，外键约束生效，对无效外键数据的插入会被数据库拦截并报错。
- 能够使用 SELECT 语句完成基础查询、条件筛选、多表关联与聚合统计，实现了参考查询题目与自定义查询。
- 成功执行 UPDATE 与 DELETE 操作，完成了学生学籍信息与课程成绩的更新、删除，掌握了数据修改的基本流程。

## 实验体会

- 通过本次实验，我对 openGauss 数据库的远程连接与数据操作有了完整的实践，理解了不同工具在数据库管理中的分工。
